Je fais cette page pour rediriger facilement les personnes qui me posent des questions sur les outils que j'utilise, mais ce n'est pas moi qui vous incitera à consommer plus !

## Matériel

- Ordinateur portable : Apple [MacBook Pro 14" 2023](https://support.apple.com/en-us/111340) (M2 Max), une machine incroyable
- J'ai monté mon ordinateur de bureau en 2012, que je fais progressivement évoluer depuis
- Écran : LG 34WN780-B
- Téléphone : Google Pixel 8a
- Liseuse: [BOOX Go 10.3](https://euroshop.boox.com/products/boox-go-10-3) sous Android pour utiliser Zotero
- Souris et clavier : Logitech MX Keys & MX Master 3
- 2 disques réseaux:
    - Synology DS725+ ;
    - Synology DS723+ pour les backups offsite.
- Serveurs : quelques Raspberry Pi suffisent pour héberger mes services et pages publiques, comme ce site
- 2 vélos :
    - [Elops Single Speed 500](https://www.decathlon.fr/p/velo-ville-single-speed-500-gris-carbone/306292/c383m8749510), avec un support SP Connect pour le téléphone ;
    - Et un vieux vélo Peugeot de 1980 qu'un ami a retapé entièrement 🚲

## Systèmes d'exploitation

- OS principal : j'utilise NixOS avec [Lix](https://lix.systems/) car la reproductibilité est important pour moi. Ma configuration est hébergée [ici](https://github.com/thomas-bouvier/dotfiles). Mon MacBook est supporté grâce au projet [Asahi Linux](https://asahilinux.org).
- OS mobile : Android 17. Mais j'aimerais passer à [GrapheneOS](https://grapheneos.org/) dès que possible.


## Applications mobiles

Je télécharge la plupart de mes applications sur le [Neo Store](https://f-droid.org/packages/com.machiav3lli.fdroid/). Je n'utilise pas d'application Google, étant donné qu'elles s'immiscent un peu trop dans ma vie privée.

- Utilitaires basiques : Fossify Contacts, Fossify Phone, Fossify File Manager, Fossify Calendar, Fossify SMS Messenger, WeatherMaster, [OSS Document Scanner](https://ossdocumentscanner.akylas.fr/).
- Messages : [Signal](https://signal.org/download/)
- Filtre spam : [Saracroche](https://saracroche.org/)
- Authentification à 2 facteurs : [Stratum](https://stratumauth.com/)
- Emails : [Thunderbird](https://www.thunderbird.net/fr/mobile/)
- Social : [Bluesky](https://bsky.social) comme client Bluesky et [phanpy](https://phanpy.social/) comme client Mastodon.
- Podcasts : [AntennaPod](https://antennapod.org/). J'ai monté un petit serveur gpodder pour sauvegarder l'état de lecture des épisodes.
- Clavier : [FlorisBoard](https://florisboard.org/)
- Cartes : [Geovelo](https://geovelo.app/fr/) et [Cartes IGN](https://www.ign.fr/telechargez-application-cartographique-cartes-ign)
- Notes : [Obsidian](https://obsidian.md/)
- Porte-cartes : [Catima](https://catima.app/)
- Lecteur de flux RSS : [Flus](https://flus.fr/)
- Navigateur : [Fennec](https://f-droid.org/fr/packages/org.mozilla.fennec_fdroid/). J'utilise les extensions suivantes : [DarkReader](https://darkreader.org/), [Consent-O-Matic](https://consentomatic.au.dk/), [Ophirophox](https://ophirofox.ophir.dev/), uBlock Origin.
- Gestionnaire de mots de passe : [Bitwarden](https://bitwarden.com/)
- Launcher : [Niagara Launcher](https://niagaralauncher.app/)
- Transferts de fichiers : [LocalSend](https://localsend.org/)
- Photos : [ReFra](https://github.com/IacobIonut01/ReFra) comme galerie photo et [Immich](https://immich.app/) pour l'archivage.

- Emails : [Thunderbird](https://www.thunderbird.net/fr/desktop/)
